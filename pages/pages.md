## Ghost 配置步骤

1. 创建 Page → 输入 **Page Title**（即表中的 Ghost Page Title）
2. 添加 HTML Card → 粘贴对应文件的完整 HTML 内容
3. 打开 Page Settings（齿轮图标）:
   - **Meta title**: 填写表中的 Meta Title
   - **Meta description**: 填写表中的 Meta Description
   - **OG image / Twitter image**: 上传主应用截图
4. 发布页面
